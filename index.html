Cambridge IGCSE 0478 Pseudocode Quick Reference (2026–2028)

                

                
            

            

                

                    

                        
1. General Style & Identifiers (p. 35–36)

                        
    
                            
  • Keywords in UPPER CASE (e.g. DECLARE, IF, REPEAT).
    • 
                            
  • Identifiers in PascalCase starting with a capital letter (NumberOfPlayers).
    • 
                            
  • No underscores (_) allowed in variable or procedure names.
    • 
                            
  • Indentation: 4 spaces for blocks; 2 spaces for THEN, ELSE, and CASE clauses.
    • 
                        

                    

                    

                        
2. Variables, Constants & Arrays (p. 36–38)

                        
DECLARE Counter : INTEGER
DECLARE TotalToPay : REAL
DECLARE GameOver : BOOLEAN
CONSTANT HourlyRate ← 6.50
DECLARE Names : ARRAY[1:30] OF STRING
DECLARE Grid : ARRAY[1:3, 1:3] OF CHAR

                    

                    

                        
3. Selection: IF & CASE (p. 42–43)

                        
IF Score >= 50
  THEN
    OUTPUT "Pass"
  ELSE
    OUTPUT "Fail"
ENDIF

CASE OF Move
  'W' : Position ← Position - 10
  'S' : Position ← Position + 10
  OTHERWISE OUTPUT "Beep"
ENDCASE

                    

                    

                        
4. Iteration: FOR, REPEAT, WHILE (p. 44–45)

                        
FOR Index ← 1 TO 10 STEP 2
    OUTPUT Index
NEXT Index

REPEAT
    INPUT Password
UNTIL Password = "Secret"

WHILE Number > 9 DO
    Number ← Number - 9
ENDWHILE

                    

                    

                        
5. String & Library Routines (p. 40–41)

                        
    
                            
  • LENGTH("Happy Days") → 10
    • 
                            
  • LCASE('W') → 'w' | UCASE("Hi") → "HI"
    • 
                            
  • SUBSTRING("Happy Days", 1, 5) → "Happy" (1-indexed)
    • 
                            
  • DIV(10, 3) → 3 | MOD(10, 3) → 1
    • 
                            
  • ROUND(4.567, 1) → 4.6 | RANDOM() → 0.0 to 1.0
    • 
                        

                    

                    

                        
6. Procedures, Functions & Files (p. 46–48)

                        
PROCEDURE Line(Size : INTEGER)
    OUTPUT "Size: ", Size
ENDPROCEDURE
CALL Line(60)

FUNCTION Square(X : INTEGER) RETURNS INTEGER
    RETURN X * X
ENDFUNCTION
OUTPUT Square(5)

OPENFILE "FileA.txt" FOR READ
READFILE "FileA.txt", LineOfText
CLOSEFILE "FileA.txt"
